2. Allgemeine Hinweise

Der Schutz Ihrer persönlichen Daten ist uns wichtig. Personenbezogene Daten sind alle Informationen, mit denen eine natürliche Person direkt oder indirekt identifiziert werden kann.

Personenbezogene Daten werden auf dieser Website nur verarbeitet, soweit dies für den Betrieb der Website, die Bereitstellung unserer Vereinsinformationen oder die Kommunikation mit Besuchern erforderlich ist.

3. Bereitstellung und Hosting der Website

Unsere Website wird technisch unter anderem über GitHub Pages bereitgestellt.

Beim Aufruf der Website können technisch notwendige Daten verarbeitet werden. Hierzu können insbesondere die IP-Adresse, Datum und Uhrzeit des Zugriffs, Browserinformationen, Geräteinformationen sowie die aufgerufene Seite gehören.

Die Verarbeitung erfolgt zur sicheren und funktionsfähigen Bereitstellung unserer Website.

4. Backend über Render

Für bestimmte Funktionen unserer Website, insbesondere für Vereinsnews, den geschützten Vorstandsbereich und das Kontaktformular, verwenden wir ein extern betriebenes Backend.

Dieses Backend wird über den Hosting-Dienst Render bereitgestellt.

Bei der Kommunikation mit diesem Backend können technisch notwendige Verbindungsdaten wie die IP-Adresse verarbeitet werden.

5. Kontaktformular

Wenn Sie uns über unser Kontaktformular eine Nachricht senden, werden die von Ihnen eingegebenen Angaben verarbeitet.

Dazu gehören insbesondere:

  • Name
  • E-Mail-Adresse
  • Betreff
  • Nachricht

Diese Daten werden ausschließlich dazu verwendet, Ihre Anfrage zu bearbeiten und mit Ihnen Kontakt aufzunehmen.

Für den technischen Versand der Nachricht per E-Mail verwenden wir den Dienst Resend.

Die Daten werden nur so lange gespeichert, wie dies für die Bearbeitung Ihrer Anfrage oder aufgrund gesetzlicher Aufbewahrungspflichten erforderlich ist.

6. Vereinsnews und Cloudinary

Auf unserer Website veröffentlichen wir Vereinsnews. Bilder zu diesen News können über den Cloud-Dienst Cloudinary bereitgestellt werden.

Beim Laden dieser Bilder stellt Ihr Browser eine Verbindung zu den Servern des jeweiligen Anbieters her. Hierbei kann insbesondere Ihre IP-Adresse technisch verarbeitet werden.

7. FUSSBALL.DE

Auf unserer Website verwenden wir Widgets von FUSSBALL.DE, um beispielsweise aktuelle Spiele, Spielpläne und Tabellen anzuzeigen.

Beim Laden dieser Inhalte wird eine Verbindung zu Servern des Anbieters hergestellt. Dabei können technisch notwendige Informationen wie die IP-Adresse und Browserinformationen übertragen werden.

8. Google Fonts

Auf Teilen unserer Website können Schriftarten von Google Fonts verwendet werden.

Werden diese Schriftarten direkt von Google geladen, kann beim Besuch der Website eine Verbindung zu Servern von Google hergestellt werden. Dabei kann insbesondere die IP-Adresse des Besuchers übertragen werden.

9. Instagram

Unsere Website enthält einen Link zu unserem Instagram-Auftritt.

Erst wenn Sie diesen Link anklicken, verlassen Sie unsere Website und werden zu Instagram weitergeleitet.

Auf die dortige Datenverarbeitung haben wir keinen Einfluss.

10. Vorstand-Login

Für berechtigte Vorstandsmitglieder steht auf unserer Website ein geschützter Login-Bereich zur Verfügung.

Nach erfolgreicher Anmeldung wird ein zeitlich begrenztes Anmelde-Token im SessionStorage des Browsers gespeichert.

Dieses Token dient ausschließlich dazu, die Anmeldung während der aktuellen Browsersitzung aufrechtzuerhalten.
